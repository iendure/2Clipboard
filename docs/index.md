# 2Clipboard

> Notify and copy: one binary that sends everything you produce to the
> clipboard, with traceable metadata ready to paste.

2Clipboard is a Bash CLI for developers, LLM workflows, engineering logs,
zettelkasten and shortcut daemons. It generates, formats and copies project
codes, file attachments with metadata headers, command output and boolean
validations — all in a single, portable, dependency-light script.
